# 📝 ArteNote - Page Vitrine

## 🎯 Description

Page de présentation professionnelle du projet **ArteNote**, créée pour présenter le projet dans un portfolio et lors d'échanges professionnels.

## 📁 Fichiers

- `artenote.html` - Page HTML principale
- `artenote-styles.css` - Feuille de styles complète
- `artenote-script.js` - Animations et interactions JavaScript

## ✨ Fonctionnalités

### Design & UX
- ✅ Design moderne avec dégradés violets (#430b66)
- ✅ Animations fluides et professionnelles
- ✅ Responsive (mobile, tablette, desktop)
- ✅ Effets de parallaxe et hover
- ✅ Barre de progression au scroll

### Sections
1. **Hero** - Présentation principale avec mockup animé
2. **Features** - 6 fonctionnalités principales détaillées
3. **Tech Stack** - Technologies utilisées (Frontend, Backend, Services, UX)
4. **Roadmap** - État du développement avec timeline interactive
5. **Contact** - CTA et liens vers portfolio/GitHub

### Interactions
- Navigation fluide avec scroll smooth
- Animations au défilement (fade-in, slide)
- Compteurs animés dans les statistiques
- Effet typewriter sur le titre principal
- Effet 3D sur le mockup au survol
- Raccourcis clavier (ESC, Ctrl+K)

## 🚀 Utilisation

### En local
1. Ouvrir directement `artenote.html` dans un navigateur
2. Ou via serveur local : `npx serve public`

### Sur GitHub Pages
Le fichier est accessible via :
```
https://aruthla.github.io/Portfolio/artenote.html
```

### Dans le portfolio React
Le lien a été mis à jour dans `Projects.jsx` pour pointer vers la page vitrine.
